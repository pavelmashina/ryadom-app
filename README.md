# Рядом

Первая работающая версия мобильного веб-приложения для владельцев питомцев. React + TypeScript + Vite. Молочно-зелёный интерфейс, полный календарь месяца над планом дня. Это веб-приложение, не нативная версия iOS/Android.

## Запуск

Нужны Node.js 22+ и pnpm 11+ (или npm).

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

Разработка: http://127.0.0.1:5173. Предпросмотр сборки: http://127.0.0.1:4173. Серверы привязаны к localhost. Публикация подготовлена для https://pavelmashina.github.io/ryadom-app/ через GitHub Pages. Зафиксированный pnpm-lock.yaml обеспечивает повторяемые зависимости. При использовании npm вместо pnpm: `npm install`, затем соответствующие `npm run …`.

## Что работает

- Полный месяц, выбор даты, переходы между месяцами, сегодня, легенда категорий и доступные подписи дат.
- События: дата, время/весь день, категория, заметка, разовые/ежедневные/еженедельные, включительная дата окончания. Выполнение отдельно для каждой даты, отмена выполнения, сворачиваемые завершённые. Перенос незавершённых разовых событий и список просроченных.
- Собственные команды, запись занятий с датой, длительностью, успешными/общими повторами и заметкой. Дневник, планирование, шкала усвоения для каждой команды.
- Здоровье: история веса; визиты, анализы/УЗИ, прививки, назначения; связь записи с новым календарным событием; предпросмотр сводки для врача.
- Запасы: фактический остаток, размер упаковки, расход владельца г/день, прогноз количества дней, отдельное пополнение, список покупок. Отметка покупки не меняет запас. Остаток не списывается автоматически.
- Профиль, переключение/добавление питомцев, отдельные данные каждого питомца. PDF/PNG/JPEG/WebP документы до 2 МБ сохраняются локально и скачиваются.
- Автосохранение после успешной проверки данных, экспорт/восстановление JSON-копии всех питомцев и документов. Восстановление проверяет формат и требует явного действия «Заменить данные этой копией». Ошибка сохранения не выдаётся за успех; повреждённое хранилище не перезаписывается автоматически.

При первом запуске есть только имя Масюша. Порода, дата рождения, пол, медицинские сведения и занятия пусты. Отдельный демонстрационный питомец «Бублик · пример» добавляется через верхнюю панель → демонстрационный пример. Пример явно помечен, реальные данные не подменяет.

## Правило усвоения v1

Это изменяемое продуктовое допущение, **не научная или медицинская методика**. Константы находятся в `src/domain.ts` (`MASTERY_RULE`).

1. Выбираем последние 5 занятий конкретной команды по дате. При одинаковой дате более поздняя запись считается более новой.
2. Складываем успешные и все повторы; округляем `(успешные / все) × 100` до целого процента. Это взвешенный результат, не среднее процентов занятий.
3. Подпись соответствует отображаемому округлённому проценту: 0–39 «Начинает понимать», 40–69 «Пока нестабильно», 70–89 «Выполняет уверенно», 90–100 «Хорошо усвоено».
4. Без занятий: «Ещё не оценено», процент отсутствует. При менее 3 занятий **или** менее 10 повторов в выбранном окне: «Предварительная оценка», даже при 100%.
5. Показываются количество занятий/повторов, число успешных, недавние результаты и последняя дата. Шкала имеет текст и доступное значение. Результат обновляется после сохранения занятия.

Валидация: только целые повторы, всего 1–1000, успешно 0–всего, длительность 1–600 минут. Будущие занятия планируются через календарь, а не записываются как состоявшиеся.

## Хранение и ограничения

Данные хранятся в localStorage этого браузера, ключ `ryadom:v1`. Они не синхронизируются между устройствами/вкладками и не защищены отдельной авторизацией. Не редактируйте одновременно в нескольких вкладках. Очистка данных сайта или приватный режим может привести к потере данных — регулярно скачивайте копию. Копия содержит документы; храните её как личный файл. Лимит localStorage зависит от браузера; документы занимают больше места из-за base64. Приложение сообщает об ошибке квоты и не применяет несохранённое изменение.

Настройка напоминания сохраняется, **доставка уведомлений не реализована**. Сводка врача — предпросмотр, без PDF-экспорта. Нет backend, аккаунтов, облака, автосписания корма, удаления/редактирования истории занятий. После первой успешной загрузки service worker сохраняет оболочку приложения для работы без сети. Для обновления закройте все окна приложения и откройте его снова. Первоначальный приватный UX PDF в проект не включён. Карты, специалисты, чаты, маркетплейс, рейтинги и поиск питомца вне этого MVP.

## Проверки

Unit tests: повторение дат на границах месяцев/лет/високосного года и смены времени, окончание повторения, независимость выполнения и перенос, процент и пороги усвоения, окно последних пяти, малый объём наблюдений, пустые данные, валидация повторов, изоляция питомцев, сохранение и отказ при повреждении/квоте. `pnpm build` включает строгую проверку TypeScript.

## Структура

`domain.ts` — модель, схемы и расчёты; `storage.ts` — сохранение/копии; `Calendar`, `EventForm`, `Training`, `Health`, `Stock` — экраны; `components.tsx` — общие формы/карточки/диалог; `App.tsx` — навигация и действия. Дальнейший шаг: уточнить платформу, затем выбрать подход к синхронизации и уведомлениям.

## Публикация и установка

Workflow .github/workflows/deploy.yml проверяет тесты, собирает приложение и публикует dist после изменений main. В Settings → Pages выберите GitHub Actions. На бесплатном тарифе GitHub репозиторий должен быть Public.

Ссылка: https://pavelmashina.github.io/ryadom-app/ . На iPhone откройте в Safari → Поделиться → На экран Домой. На Android откройте меню Chrome → Установить приложение / Добавить на главный экран. Данные остаются в браузере устройства; перед сменой адреса сайта сохраните JSON-копию.
