# Занятия и хранение данных — 6 октября 2026

## Реализовано

- Несколько команд в тренировке, оценка 1–5 и режим для каждой, общий и отдельные комментарии, дата и необязательная длительность.
- Добавление команды прямо в форме, просмотр и редактирование тренировок, история команды с переходами к занятиям.
- Названия команд уникальны без учёта регистра и крайних пробелов в пределах питомца.
- Старые занятия с количеством повторов сохранены в архиве: оценки им не выдумываются.
- Все разделы сохраняются в аккаунте. Интерфейс ждёт подтверждения, показывает ошибки, блокирует повторную отправку. Сохранение транзакционное.
- Конфликт изменений на другом устройстве не перезаписывает данные: требуется обновить страницу.

## Таблицы и доступ

| Таблица | Назначение |
| --- | --- |
| pets | Питомец и существующие календарь, здоровье, запасы, документы |
| commands | Команды питомца |
| training_sessions | Дата, длительность, общий комментарий, временные метки |
| training_command_results | Команда в тренировке, оценка, режим, комментарий |
| account_state | Выбранный питомец и версия аккаунта |

Все пять таблиц имеют RLS и отдельные политики SELECT/INSERT/UPDATE/DELETE с `auth.uid() = user_id`. UPDATE проверяет старую и новую строки. Анонимный доступ закрыт. Составные внешние ключи запрещают связи с чужим пользователем или другим питомцем. БД запрещает оценки вне 1–5, повтор команды и тренировку без результатов.

RPC load_app_state и save_app_state работают с правами пользователя (SECURITY INVOKER), фиксированным search_path и RLS. Сохранение блокирует строку версии и проверяет ожидаемую revision.

Прежняя user_state сохранена для чтения собственных данных и переноса при первом входе. Запись старым клиентом закрыта. Автоматический импорт общего localStorage удалён: он мог переносить данные предыдущего пользователя в новый аккаунт. Выход сразу очищает интерфейс; смена аккаунта в другой вкладке перезагружает состояние.

## Прогресс

Среднее последних пяти тренировок с данной командой, упорядоченных по дате, затем created_at и id. Нет истории — «Новая»; <2.5 — «Изучаем»; <3.5 — «Нестабильно»; <4.5 — «Уверенно»; иначе «Усвоено». Статус считается до округления; отображается один десятичный знак. При одной или двух тренировках оценка предварительная. Редактирование даты и оценки пересчитывает прогресс.

## Ограничения

- Подтверждение регистрации настоящим письмом не проверено полностью: Supabase отверг тестовые адреса example.com. Проверены интерфейс и обработка ответа регистрации; реальный вход/выход и изоляция проверены на временных подтверждённых аккаунтах. Подтверждение email в проекте включено.
- Нужен интернет. Service worker кэширует оболочку, но приватные данные офлайн не сохраняются. Новая оболочка активируется после загрузки без принудительного сброса открытой формы; для отображения обновления перезагрузите страницу.
- Остальные разделы и документы остаются в JSON питомца для совместимости. Сохранение передаёт аккаунт целиком: решение рассчитано на текущий небольшой объём данных.
- Старые локальные данные не удалены, но не импортируются автоматически. Перенос возможен через явное восстановление резервной копии.
