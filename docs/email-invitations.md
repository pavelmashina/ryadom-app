# Приглашения по email — «Рядом»

## Активация автоматической отправки

Письма отправляются через Supabase Edge Function `pet-invitation-email` и провайдер [Resend](https://resend.com/docs/send-with-supabase-edge-functions). Для реальной доставки нужны:

1. Подключить и подтвердить домен отправителя в Resend (SPF/DKIM).
2. Создать в Resend API key с разрешением отправки писем.
3. В Supabase (проект Pets App, Edge Functions → Secrets) задать:
   - `RESEND_API_KEY` — API key из Resend.
   - `PET_INVITE_FROM_EMAIL` — например, `hello@<подтвержденный-домен>`.
4. Проверить письмо на адрес, к которому вы имеете доступ. Успех API означает, что провайдер принял письмо, а не гарантию попадания во «Входящие».

Секреты **нельзя** записывать в репозиторий или передавать в клиентский код. Если они отсутствуют, Edge Function возвращает понятную ошибку 503 и не сообщает об успешной отправке.

## Правила

- Доступна только владельцу карточки питомца после входа.
- Отправитель в письме и `Reply-To` берутся из подтверждённого email владельца; технический `From` использует подтверждённый почтовым провайдером домен (иначе доставка будет отклонена).
- Получатель вводится пользователем; имя питомца и код проверяются и подставляются сервером.
- Одинаковый HTML/text-шаблон письма для всех приглашений.
- 1 приглашение одному получателю на питомца за 2 минуты; не более 30 попыток на отправителя в сутки.
- Отправка письма не создаёт членство: получатель проходит вход/регистрацию и отправляет запрос. Владелец одобряет запрос в управлении доступом.
- Ошибки доставки отображаются пользователю; подтверждение отправки выводится только при успешном ответе Resend.
