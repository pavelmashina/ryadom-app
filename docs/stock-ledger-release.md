# Запасы — релиз базы и интерфейса (ТЗ 177–223)

## Источник данных и миграция
- Источник фактического остатка: `public.stock_items.current_quantity` (в базовых единицах).
- `stock_transactions` фиксирует изменения и фактически списанные величины; `stock_consumption_rules` хранит историю версий правил.
- Существующий остаток корма перенесён однократно как `correction` с комментарием «Начальный остаток при миграции». Предшествующие списания не выдумываются.
- Старые поля `pet.stock/pack/ration` сохранены для чтения прежних данных, но редакторы этих полей больше не доступны в новой вкладке.
- Покупки используют `shopping_credit` и стабильный идентификатор покупки: повторная отправка не зачисляет корм дважды.

## Права
- Данные разделены по `pet_id`, таблицы включают RLS.
- SELECT только активным `pet_members`.
- Мутации через `public.stock_mutate` с явной проверкой роли `owner/editor`.
- Автоматические списания защищены `unique(consumption_rule_id, scheduled_for)` и ограничены доступным остатком.

## Фоновая обработка
- Активный Supabase Cron `pet-stock-consumption-hourly` запускает `pet_private.process_all_stocks()` каждый час.
- Загрузка раздела вызывает безопасный `stock_snapshot`, который также догоняет пропущенные списания.
- Редактирование правила сохраняет уже созданные операции.

## Push (требует завершения подключения)
- Созданы таблицы состояний предупреждений и очереди push, включая дедупликацию по смене состояния.
- В Supabase развернута отдельная Edge Function `pet-stock-push-worker`; текущий `pet-push-worker` календаря не изменён.
- **Фоновое расписание вызова этой Edge Function не активировано**: применение миграции с защищённым серверным токеном было заблокировано. Нельзя считать доставку push по запасам действующей, пока расписание не будет создано и успешно проверено.
- При активации расписания необходимо использовать существующую серверную авторизацию и секрет в Supabase Vault; никогда не помещать его в репозиторий или браузер.
- Проверить тестовое уведомление на двух устройствах и отсутствие повторов для одного уровня остатка.
