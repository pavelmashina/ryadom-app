# Статусы задач

Issues проекта «Рядом» используют те же статусы, что и Gym App:

| Статус | Значение | GitHub |
| --- | --- | --- |
| **Новая задача** | Ожидает реализации | Open |
| **Выполнена** | Правки внесены, ждут твоей проверки | Open |
| **Проверена** | Ты проверил и принял работу | Closed |

[Автоматизация](../.github/workflows/issue-statuses.yml) создаёт эти три labels, помечает открытые Issues без статуса как **Новая задача** и следит, чтобы статус был только один. Когда ты ставишь **Проверена**, Issue автоматически закрывается. Если снова откроешь проверенную задачу, она вернётся в статус **Новая задача**.

Новые Issues, созданные Telegram-ботом @GymAppEditBot после выбора «🐾 Рядом», также получают **Новая задача**. Ранее закрытые Issues не помечаются проверенными автоматически.

Чтобы сменить статус, открой Issue и справа в **Labels** выбери **Выполнена** либо **Проверена**. Владелец лично проверяет результат, автоматического ИИ-ревью нет.
