# Восстановление пароля

## Настройка Supabase перед использованием

В Authentication → URL Configuration Site URL и разрешённый Redirect URL настроены на `https://pavelmashina.github.io/ryadom-app/`. Первоначальный адрес localhost исправлен; владелец подтвердил успешный вход с телефона после восстановления доступа.

В Authentication → Emails проверьте доставку и шаблон Reset Password: он должен содержать стандартную ссылку `{{ .ConfirmationURL }}`. Для доставки произвольным пользователям требуется настроенный SMTP: встроенная почта Supabase имеет ограничения. Проверку реального письма завершает владелец почтового ящика; пароль вводится только в приложении.

## Реализация

- backend.ts отправляет POST /recover с redirect_to на корень приложения, проверяет recovery-токен через GET /user и меняет пароль через PUT /user.
- Токены сразу удаляются из адресной строки и хранятся только в sessionStorage текущей вкладки до завершения. Обычная сессия другого пользователя не подменяется.
- CloudGate.tsx обрабатывает recovery-ссылки до загрузки данных аккаунта, включая переход в уже открытой вкладке и повторный запуск эффекта React.
- PasswordRecovery.tsx содержит формы email и нового пароля, подтверждение, загрузку, блокировку повторной отправки, понятные ошибки и возврат ко входу.
- После успешной смены временная сессия очищается; интерфейс предлагает вход с новым паролем. Сама смена выполняется Supabase и не требует доступа к таблицам питомцев.
- recovery.test.ts проверяет адрес возврата, ограничение частоты писем, проверку и удаление токенов из URL, истечение ссылки, валидацию, сохранение и изоляцию другого аккаунта. Всего с существующими тестами — 70 успешных проверок; production-сборка проходит.

Документация: [восстановление пароля](https://supabase.com/docs/guides/auth/passwords), [адреса возврата](https://supabase.com/docs/guides/auth/redirect-urls).
